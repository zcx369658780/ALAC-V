# Phase 2A Owner 决策摘要

## 1. 一句话结论

Phase 2A 的可行路线是：**冻结 DINOv2 教师 + ≤10M 参数的学生（adapter + predictor）+ 程序化无标签合成数据**，
用 3 条机制臂 + 1 条 predictor-only 对照做**受控比较**；在当前约束下，这是唯一能在 12GB 单卡、
无自然图像、无标签条件下产出**可证伪结论**的设计。

**不推荐**任何形式的 DINOv2 微调或联合训练：显存与可复现性都不允许。

## 2. 推荐方案（供决策）

| 项 | 推荐 |
|---|---|
| 主实验 | A2（JEPA 式块预测 + adapter）作为**唯一 primary arm**；B2/C2 为 secondary（Holm 校正） |
| 对照 | F0（冻结）、A1（只训 predictor）、R0（随机初始化 adapter） |
| 数据 | DS-0002（纯程序化，2,000/300/300 场景，按 base scene 分组切分） |
| 评估 | 检索 Recall/mAP、同源异源 AUC、跨视图一致性、线性探针、坍塌诊断、资源 |
| 预算 | ≤21 个训练 run，GPU **21–35 h**（粗略：1.0–1.7 h/run），磁盘约 20 GB（含教师特征缓存） |
| 成功判据 | H1：**A2** 相对 F0 的 Recall@1 ≥ +3 pp 且 95% CI 下界 > 0（达成实践阈值且方向为正）；只有 CI 下界 > 3 pp 才称统计上证明 ≥ 3 pp |

**为什么 A2 作为主臂（这是先验，不是结论）**：
1. 它与本项目"预测式视觉"的长期方向一致；
2. 在冻结教师上实现最直接（目标即教师 patch 特征）；
3. 失败时的信息量最大：如果连"预测教师特征"都不能提升，则"适配器容量/冻结上界"是可解释的失败原因。

**明确不预设 A2 最优**：B2/C2 的 secondary 结果与 H3b 的两个预注册对比照实报告；
若 B2/C2 更好，不得因 A2 是主臂而淡化。三臂参数为 7.0M / 4.7M / 7.0M，**不声称同预算**，
H3 必须同时给出单位参数收益。

## 3. 替代方案与取舍

| 方案 | 优点 | 缺点 | 何时选它 |
|---|---|---|---|
| 只做 C（掩码潜表征） | 最便宜、无需跨视图增强 | 目标与教师同图，可能只学到"补全" | 若 GPU 预算 < 8 h |
| 只做 B（跨视图蒸馏） | 与 DINO 系最接近，工程成熟 | 与现有增强不变性重叠，边际信息少 | 若目标是"复现 DINO 式收益" |
| 不做实验，仅做设计 | 零风险 | 无法回答 RQ | 不推荐：设计已足够具体，成本可控 |

## 4. 主要风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 合成域结论无法外推自然图像 | 高 | 高 | 预注册写明边界；自然图像另立 D-1 决策 |
| 冻结教师上界导致提升 <3 pp | 中 | 高 | 如实报告"无证据"；不调阈值 |
| 评估泄漏（场景标签进训练） | 低 | 高 | 字段白名单 + 单测 + 审计 |
| 12GB 显存不足 | 低 | 中 | batch 8–32 + 梯度累积；缓存特征 |
| 许可问题（I-JEPA/V-JEPA/MAE/SimSiam 代码 NC；V-JEPA 2 代码为 MIT+Apache-2.0） | 中 | 中 | 独立实现；只使用 Apache-2.0 的 DINOv2 权重 |
| 3 seed 统计功效不足 | 中 | 中 | 300 测试场景 + 配对 bootstrap |
