# ADR-0005：Foveation 用"双产物"

## 背景

任务单要求：重要区域保留高分辨率、周边低分辨率、保留原图以支持局部高清回溯、不得简单永久丢弃焦点外信息。

"单张马赛克"与"双流编码"各有优劣：马赛克可被人眼/单流模型直接消费，但若画布等于原分辨率则存储收益有限；双流（fovea 高清 + 周边低清）编码更符合生物视觉且特征更省，但没有一张直观的合成图。

## 决策

foveation 模块同时产出两类资产：

1. **`foveated.webp`（马赛克）**：画布 = 原图 1/2 尺寸。
   - 周边（画布全幅）：原图 1/4 → 上采样 2× 填入（等效原图 1/4 信息）；
   - 旁中央环（距 ROI 中心 1.0–1.75 倍 ROI 半径）：原图 1/2 直接贴入；
   - 中央凹（ROI 矩形）：原图 1/2 直接贴入（相对周边高 4 倍面积密度）。
   - 边界用 8 px 羽化过渡，避免硬接缝。
2. **`roi/roi_XX.webp`（全分辨率裁片）**：ROI 在原图像素坐标上的裁切，**1:1 原始像素**，用于真正的高清回溯与"局部再编码"。

另外 `roi.json` 记录：`x,y,w,h,score,method,canvas_scale`，坐标一律用**原图像素**，不受派生缩放影响。

## 理由

- 马赛克是"看得见的 foveation"，可直接作为单流编码输入，也是给 Owner 演示的直观产物。
- 全分辨率 ROI 裁片满足"重要区域保留高分辨率"的硬要求，且让回溯质量可被 PSNR/SSIM 量化。
- 画布取 1/2 是工程折中：整图 1/2 已比原图省 75% 像素；再叠加 WebP 对平滑周边的高压缩率，典型体积为原图 15–30%。
- **信息未丢弃**：原始文件始终在 `data/raw` 只读保存；周边低清只是"表示"，不是"删除"。

## 后果

- **正面**：C 变体的特征输入有明确解剖结构（fovea/parafovea/periphery + 全分辨率 ROI），便于消融。
- **负面**：马赛克本身是派生图像，若 ROI 选错，fovea 处放的是错误内容 → 必须在实验中度量"ROI 命中率"，并允许 `manual` 覆盖。
- **负面**：8 px 羽化是经验参数，写入配置而非硬编码。

## 备选与否决

- 单一马赛克画布 = 原图分辨率：存储收益趋近于零，且 518 输入会把 ROI 优势抹平。否决。
- 直接丢弃周边（只存 ROI）：公然违反"不得永久丢弃焦点外信息"。否决。
- 对数极坐标（log-polar）重采样：理论漂亮，但 DINOv2 未在极坐标上预训练，特征分布偏移大，留待 Phase 2 研究。本阶段用矩形 ROI + 环形过渡这一可解释近似。
