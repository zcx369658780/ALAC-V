# ADR-0007：ROI 重要性用无监督梯度能量

## 背景

Foveated ROI 需要"重要区域"。可选：显著性模型（需额外权重）、目标检测（需标签）、人工标注（不可扩展）、手工规则。

## 决策

`method = gradient_energy_v1`：

1. 转灰度 → 高斯模糊 σ=1 → Sobel 梯度幅值 → 归一化到 [0,1]；
2. 积分图 + 滑窗求"窗口能量和"，窗口边长 = `roi_frac * min(H, W)`（默认 0.25）；
3. 取 argmax 作为主 ROI；候选窗口做 NMS（IoU > 0.3 抑制）得到至多 `max_rois` 个；
4. 边界夹紧到图像内，保证 `w,h >= 32`。

同时支持 `--roi x,y,w,h` 手工覆盖（`method=manual`），供 Owner 指定。

## 理由

- 零额外模型、零下载、确定性、毫秒级；
- 对"纹理丰富/边缘密集"的区域有效，恰好也是高频细节最需要保真的区域；
- 可解释：分数就是窗口内梯度能量和。

## 后果

- **正面**：不引入任何语义先验，符合"视觉为主、不自欺"的基线定位。
- **负面**：**它不知道"语义重要"** —— 一张图里最锐利的可能是背景树叶而不是人脸。这是本阶段已知局限，写入风险登记册（R-03），并在实验里报告"ROI 命中率"（合成数据集中 ROI 有真值）。
- **负面**：纯色/低对比图会退化为任意位置 → 加兜底：能量图全零时取图像中心。

## 备选与否决

- 用 DINOv2 patch 特征的自注意力/范数做显著性：可作为 Phase 2 的对照（`method=patch_norm_v1`），本阶段不实现，避免循环依赖（用模型选 ROI 再喂模型）。
