# ALAC-V 项目宪章

**ALAC-V = Visual-first Autonomous Learning and Adaptive Cognition**（视觉优先的自主学习与自适应认知）

## 1. 一句话定义

构建一种**不依赖 LLM 作为核心推理引擎**的视觉智能系统：以视觉编码为入口，以多层次视觉记忆为载体，以自主视觉学习与未来状态预测为能力目标，以动态计算分配为效率手段。

## 2. 长期目标（按依赖顺序，不可跳级）

| # | 目标 | 说明 | 当前阶段 |
|---|---|---|---|
| G1 | 高效视觉编码与压缩 | 把图像变成紧凑、可检索、可回溯的表示 | Phase 1 |
| G2 | 多层次视觉记忆 | 原始层 / 多尺度层 / 特征层 / 语义层，各层可独立寻址 | Phase 1 起步 |
| G3 | 自主视觉学习 | 无标签、自监督、增量式的表征与结构学习 | Phase 2+ |
| G4 | 未来状态预测 | 在视觉表征空间做时序预测，而非像素重建 | Phase 2+ |
| G5 | 动态计算资源分配 | 按区域/难度/价值分配算力（foveation、早退、缓存） | 贯穿各阶段 |
| G6 | 静态图像 → 视频 → 实时视觉流 | 时序扩展 | Phase 3+ |

## 3. 核心原则（违反即视为方案失败，而不是"权衡"）

1. **原始数据不可变**：原始图像只读归档，任何派生表示不得覆盖或删除原始文件。所有派生文件可由原始文件 + 配置重放生成。
2. **视觉为主，LLM 不参与核心推理**：不调用外部 LLM API 参与视觉推理；不把 LLM 作为编码器/检索器/控制器。文本仅用于文档与人机接口。
3. **本地优先、开源优先**：模型推理与学习以本地单机（RTX 5070 12GB + 32GB RAM）为目标；模型选型优先 Apache-2.0 / MIT 等宽松许可的开源权重；记录每个模型的许可证与来源。
4. **效率声明必须附带能力证据**：不得仅凭"特征文件更小 / 显存更低"宣称效率提升。任何压缩、降采样、foveation 的收益都必须同时报告视觉任务指标（检索准确率、相似性一致性、局部回溯质量）。
5. **可复现**：配置化、版本化、日志化。一次实验 = 一份配置 + 一个 run 目录 + 一个数据清单。
6. **不擅自扩张**：不进行未经批准的大规模数据下载；不在本阶段训练/微调 DINOv2 主干；不提前引入重型基础设施（向量库、分布式、消息队列）。
7. **隐私边界**：用户图像不上传云端；实验数据可公开、可删除、可重建。

## 4. 阶段边界（Stage Gate）

| 阶段 | 内容 | 出口条件 |
|---|---|---|
| Phase 0 | 环境审计 | 硬件/驱动/CUDA/Python/磁盘全部核验，混合精度在 GPU 上跑通 |
| Phase 1 | 静态图像视觉编码 | 归档 + 多尺度 + Foveated ROI + DINOv2 特征 + 知识库 + A/B/C 对照实验 |
| Phase 2 | 多层次视觉记忆与自主视觉学习 | **需 Owner 审核 Phase 1 后另行下达任务单** |
| Phase 3 | 视频与实时流 | 需 Phase 2 通过 |

**硬性规定：完成 Phase 1 后停止，不得自动进入视频模型训练或任何 Phase 2 工作。**

## 5. 硬件基线（不得假设更多）

- CPU：Intel Core Ultra 7 265K（8P + 12E，20 线程）
- RAM：32 GB DDR5
- GPU：NVIDIA RTX 5070，12 GB GDDR7（实测 12227 MiB），单卡
- 存储：D: 盘可用约 990 GB
- **禁止**假设多 GPU、服务器级显存、集群或云端算力

## 6. 成功标准（Phase 1）

1. 任意给定图像目录，一条命令完成：归档 → 多尺度 → Foveated ROI → DINOv2 特征 → 入库。
2. 原始图像字节级不可变（有校验和证明）。
3. 知识库可回答：给定查询图像/ROI，返回相似图像与精确 ROI 坐标，并能从原始图回溯高清局部。
4. A/B/C 三组在**同等硬件、同等数据、同等随机种子**下可复现地对比。
5. 全部数字可追溯到 run 目录与配置哈希。
6. 单元测试覆盖归档、金字塔、foveation、存储、检索五条主路径。

## 7. 非目标（本阶段明确不做）

- 不做大型基础模型预训练或 DINOv2 主干微调。
- 不做视频、光流、时序建模。
- 不做语义分割/检测/描述生成。
- 不引入向量数据库（FAISS/Milvus 等）、不引入 Web 服务。
- 不追求 SOTA 精度，只建立**可靠、可复现、可扩展的基础**。

## 8. 术语表

| 术语 | 定义 |
|---|---|
| 归档（Archive） | 把原始字节按 SHA-256 内容寻址、只读保存的过程 |
| 金字塔（Pyramid） | 同一图像在 1/1、1/2、1/4、1/8 尺度上的派生副本 |
| Foveated ROI | 对"重要区域"保留高分辨率、周边逐级降采样的单张合成表示；ROI 坐标独立存储 |
| 回溯（Backtrack） | 由特征/ROI 反查原始图像并取回该区域的高清像素 |
| 描述子（Descriptor） | 用于检索的定长向量（CLS 或其多尺度拼接） |
| 特征库（Feature Store） | SafeTensors 文件 + SQLite 元信息的组合 |
