# EXP-0002 自主视觉学习预注册（草案）

> **状态：草案，未授权运行。** 本文件只定义"如果 Owner 批准 Phase 2A.1，将如何做实验"。
> 在 Owner 批准与独立复核前：不训练、不生成 DS-0002、不下载权重。
>
> 写法遵守 EXP-0001 的教训：假设、阈值、判定规则在任何运行之前写定；结果章节运行后只追加。

## 1. 研究问题

RQ：在**无人工标签**、**冻结 DINOv2 ViT-S/14**、**RTX 5070 12GB** 的约束下，三种无标签机制
（JEPA 式潜空间预测 / 跨视图自蒸馏 / 掩码潜表征预测）中，是否存在一种能在**合成域**上
稳定提升检索与不变性、且不牺牲判别性的表征学习方案？

RQ2：只训练 predictor（不改变表征）与训练 adapter（改变表征）在指标上是否可区分？

## 2. 实验臂

| 臂 | 可训练部分 | 评估所用表征 | 目的 |
|---|---|---|---|
| **F0** | 无 | \(f_\theta(x)\)（CLS / patch 均值） | 冻结基线 |
| **A1** | predictor（3.5M） | \(f_\theta(x)\)（不变） | 证明 predictor-only 不改变表征 |
| **A2** | adapter（3.5M）+ predictor（3.5M） | \(g_\phi(f_\theta(x))\) | JEPA + 表征 |
| **B2** | adapter（3.5M）+ predictor（0.45M） | \(g_\phi(f_\theta(x))\) | 跨视图蒸馏 |
| **C2** | adapter（3.5M）+ predictor（3.5M） | \(g_\phi(f_\theta(x))\) | 掩码潜表征 |
| **R0** | 同 A2 结构但随机初始化且不训练 | \(g_{\phi_0}(f_\theta(x))\) | 容量/随机投影对照 |

**约束**：A2/B2/C2 的可训练参数预算差 ≤ 2×；训练步数、batch、数据、增强、评估完全相同。

## 3. 数据

| 项 | 规定 |
|---|---|
| 主数据 | DS-0002（**尚未生成**；2,000/300/300 base scenes 按 seed 分组切分） |
| 冒烟 | DS-0001 的 24 场景仅用于管线冒烟，不进入结论 |
| 训练可见信息 | 图像像素 + 增强参数 + mask 位置（由随机种子决定） |
| 训练不可见 | scene id、bbox、因子标签、split 之外的信息 |
| 评估标签 | 仅在第 7 节评估阶段使用 |
| 泄漏检查 | 训练 DataLoader 的字段白名单 + 单元测试；manifest 按 base scene 分组 |

## 4. 训练协议（预注册）

| 项 | 值 |
|---|---|
| 输入 | 518×518，37×37 patch |
| 教师 | 冻结 DINOv2 ViT-S/14，FP16；特征预计算并缓存 |
| Adapter | 2×Transformer block（384 维，6 头，MLP 4×） |
| Predictor | A2/C2：2×block；B2：2 层 MLP（768→384→384） |
| 优化器 | AdamW，lr 1e-3（adapter）/ 1e-3（predictor），wd 0.05 |
| batch | 32（显存不足时 16 + 梯度累积 2） |
| 精度 | AMP（bf16），教师前向 FP16 |
| 步数 | 20 epoch × 512 step = 10,240 step |
| 随机种子 | **3 个**：2026, 2027, 2028 |
| checkpoint | 每 2 epoch；最终 + 最佳（按 val 预测损失，早停耐心 3） |
| 早停 | val loss 连续 3 次不降则停 |

## 5. 评价指标

1. **检索**：Recall@1、Recall@5、mAP@10（test 300 场景 × 4 查询）；
2. **判别性**：同源/异源余弦 AUC；
3. **不变性**：同场景跨视图余弦均值；
4. **线性探针**：在冻结表征上训练逻辑回归（标签仅评估用），报告 top-1；
5. **坍塌诊断**：有效秩、参与比、最小维方差；
6. **资源**：可训练参数、峰值显存、训练时长、推理延迟、特征体积；
7. **预测质量**（A1/A2/C2）：held-out 视图上的 latent prediction error。

## 6. 假设与判定规则（先定后测）

| 编号 | 假设 | 判定 |
|---|---|---|
| **H1（主）** | 至少一个 adapter 臂（A2/B2/C2）相对 F0 的 Recall@1 提升 ≥ **3 pp** | 配对 bootstrap（按 test scene，10,000 次）95% CI 下界 > 0 → **支持**；否则**不支持** |
| **H2** | A1 与 F0 的 Recall@1 差异 ≤ **0.5 pp** | 差异 > 0.5 pp → 视为**评估管线缺陷**，先排查再继续 |
| **H3（探索）** | 三种机制之间存在可测的优劣排序 | 最优 vs 次优差异的 95% CI 不含 0 才允许声称排序；否则写"无可测差异" |
| **H4** | adapter 臂提升跨视图不变性且不牺牲判别性 | 跨视图余弦 +≥0.02 且 AUC 下降 ≤2 pp → 支持 |
| **H5** | 收益可泛化到未见 seed | test 与 val 的 Recall@1 差距 ≤2 pp 且 test 增益方向一致 → 支持 |

**多重比较**：H1 为唯一主要假设；H3/H5 为次要/探索，报告效应量与 CI，不做 p 值筛选。

## 7. 失败判据（必须预先接受）

满足任一条件即判定**本阶段未成功**，必须在报告首段写明：

1. 没有任何 adapter 臂达到 H1；
2. 最佳臂的 val→test 落差 >5 pp（合成器过拟合）；
3. 任一臂有效秩 < F0 的 50%（坍塌）；
4. 评估集/标签泄漏被证实；
5. 训练无法在 12GB 内完成且降 batch 后仍 OOM。

**不允许**的替代叙事：
- 用训练 loss 下降代替 H1；
- 用"特征更紧凑"代替任务指标；
- 在 H1 失败后改阈值或换测试集。

## 8. 统计方案

- 3 seeds：报告每个指标 mean ± std；
- 配对 bootstrap：以 test scene 为重采样单位（n=300），10,000 次，95% 百分位 CI；
- 效应量：ΔRecall@1（pp）、ΔAUC、Δ余弦；
- 不做事后分层挑选；预注册的子组只有"未见 seed"。

## 9. 数据效率（次要）

对**表现最好的一条臂**额外训练 25% / 50% / 100% 训练场景（每档 3 seeds），
绘制 Recall@1 vs 训练场景数曲线；F0 作为不随数据变化的水平线。

## 10. 资源与停止条件

- 主实验：4 个训练臂（A1/A2/B2/C2）× 3 seeds = 12 runs；F0 与 R0 不需要训练；数据效率 +9 runs；合计 ≤ 21 个训练 run；
- 预估 GPU 时间：每 run 20–40 min（缓存特征），总计 **8–16 h**；
- 若实际单 run 超过 90 min 或显存峰值 > 9 GB，暂停并重新设计，不得硬扛。
