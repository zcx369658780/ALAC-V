# EXP-0001 协议修订 AMD-0001

> **性质**：协议修订（addendum）。原始预注册 `EXP-0001` §3–§6 的假设、指标与判定阈值
> **未被覆盖或改写**；本文件记录缺陷、修正口径与对结论的影响。原始 `EXP-0001` 中
> §8 的历史数字保留原样，并标注"未修正（含缺陷）"。

## 1. 缺陷

原 `scripts/run_experiments.py::recover()` 的 A 变体重建：

1. 按 `scale = 518 / min(W, H)` 缩放整图；
2. 直接以 `int(x*scale)` 在**缩放图**上取 ROI；
3. 未应用 `fit_to_input()` 的**中心裁剪偏移** `left=(nw-518)//2, top=(nh-518)//2`；
4. 未排除落在 518 窗口之外、编码器实际看不到的 ROI 部分；
5. 缩放尺寸用 `int(w*scale)` 截断，而编码器用 `int(round(...))`，两者可能差 1 px。

后果：A 的"可见像素"包含编码器从未观测的区域，且在非正方形图上存在亚像素错位；
B/C 的对照区域与 A 不完全一致。该指标因此不能严格称为"派生表示可见像素保真度"。

## 2. 修正口径（TASK-0002 / WP2 + 第二轮复核）

新增 `src/alacv/backtrack.py`，作为唯一坐标事实来源：

- `fit_geometry()` 与 `imaging.fit_to_input()` 共用同一取整与裁剪偏移（已重构为同一函数）；
- `visible_region(box, size, 518)` 计算 ROI 与 518 中心裁剪窗口在原图坐标下的交集，
  返回 `coverage = 可见面积 / ROI 面积`；
- `reconstruct_from_visible()` 只从 **518 窗口内**的像素重建，并放大回可见交集尺寸；
- A/B/C 三种变体一律在**同一可见交集**上比较（B/C 的资产按同一 box 裁切）；
- 完全不可见的 ROI 记入 `excluded`，不伪造像素、不计算 PSNR。

评价语义明确为：**派生表示可见像素保真度**（不是从 embedding 解码重建，也不代表模型具备像素生成能力）。

**第二轮复核追加修正（2026-11-14）**：

1. **评价区域回到预注册定义**：主指标必须使用数据集 manifest 的 `gt_bbox`（目标真值框），
   而不是 ROI 算法自己选中的区域。此前用 attended ROI 计算的结果降级为**探索性次指标**，
   单独命名，不替代主指标。
2. **逐轴缩放**：Pillow 实际按 `resized_w/W` 与 `resized_h/H` 两个比例缩放，二者与名义
   `518/min(W,H)` 不相等（1024×768 → 691×518）。可见区域逆映射与 A 重建正向映射均改用
   `x_scale`/`y_scale`，消除最多 1 个输入像素的偏差。
3. **C 的 GT 区域重建规则**：GT 框可能部分/完全落在所选 ROI 之外。C 的回溯定义为
   「全分辨率 ROI 裁片覆盖处 + foveated 马赛克（1/2 画布）覆盖其余区域」的**逐像素合成**，
   而不是只评价 ROI 内部。

## 3. 复算方法与可复现性

- 脚本：`scripts/recompute_backtrack.py`（不重跑编码，不加载 DINOv2）。
- 输入：历史 run 的 `store/raw`、`store/processed` 与 SQLite 元信息（原始 run 未改动）。
- 数据：DS-0001 的 24 张基准图；**主指标使用 manifest 的 `gt_bbox`**（预注册目标区域），
  A/B/C 在同一 GT 可见交集上比较。attended-ROI 次指标才使用 C run 存储的 ROI（A/B run 用同一
  确定性 `select_rois` 复现）。
- 输出：`artifacts/experiments/EXP-0001-backtrack-corrected.json`（含逐图明细）。
- 重复：3 次 run 各算一遍，取中位数。

## 4. 结果对照

### 4.1 主指标：GT bbox 区域（预注册口径，24 张基准图 × 3 次重复，中位数）

| 变体 | PSNR (dB) | SSIM | 相对 A |
|---|---|---|---|
| A | **31.66** | **0.925** | — |
| B | **31.05** | 0.889 | −0.62 dB |
| C | **28.53** | 0.846 | **−3.14 dB** |

- 有效样本 24/24，**排除 0**；GT 区域对 518 窗口的平均可见覆盖率 **0.928**。
- **C 明显低于 A/B**，机制解释如下（基于逐图 ROI 数据，见 4.4）。

### 4.4 C 的 ROI 覆盖机制（区分 ROI_00 与全部已存裁片）

C 的配置是 `max_rois=2`，每图保存两个 ROI 裁片；编码特征源只含 `roi_00`，但**回溯表示会贴回
全部已存裁片**。因此不能用单一"58.3% 命中"解释全部差异：

| 指标（24 张基准图） | 数值 |
|---|---|
| `roi_00` IoU≥0.3 命中率 | 14/24 = **58.3%** |
| 任一已存 ROI 裁片 IoU≥0.3 命中率 | 16/24 = **66.7%** |
| 两个裁片并集对 GT 框的面积覆盖（均值） | **47.7%** |

结论应表述为：**C 的全分辨率 ROI 覆盖范围有限，平均仍有约 52.3% 的目标区域依赖 1/2 画布
马赛克上采样；这与 GT bbox 保真度下降一致。** 58.3% 只是 ROI_00 的命中率，不能单独作为
完整因果证明（低于 IoU 阈值的样本仍可能有部分全分辨率覆盖）。

逐图 `roi_boxes`、`roi_hit_iou03`、`roi_union_coverage_of_gt` 已写入
`artifacts/experiments/EXP-0001-backtrack-corrected.json` 的 `per_image`。
- B 略低于 A：B 的 L0 经过 WebP q95 二次压缩，而 A 的 518 重采样在这些合成图案上反而
  更接近原始低频结构（PSNR 对高频伪影敏感，对平滑模糊相对宽容）。

### 4.2 次指标：attended ROI 区域（探索性，不替代主指标）

| 变体 | PSNR (dB) | SSIM |
|---|---|---|
| A | 29.44 | 0.919 |
| B | 29.43 | 0.853 |
| C | 29.35 | 0.853 |

该指标只说明"模型选中区域内的保真度"，三组基本持平；它**不能**用来说明系统对真实目标的记忆能力。

### 4.3 与第一轮修订值的关系

第一轮（错误地使用 attended ROI，且用名义 scale）得到 A 29.13 / B 29.43 / C 29.35。
该组数字**作废**：既不是预注册区域，也含 1 px 坐标偏差。

## 5. 对原假设的影响

| 假设 | 原判定（原始运行） | 修正后 | 说明 |
|---|---|---|---|
| H1（B 优于 A，检索） | 未达标准 | **不变** | 召回类指标不受本修订影响 |
| H2（C 不劣于 B，检索） | 支持 | **不变** | 同上 |
| H3（C 回溯优于 A ≥2 dB） | 支持（+2.34 dB） | **拒绝（方向相反，−3.14 dB）** | 原"优势"完全来自评价区域错误 |
| H4（C 比 B 省存储） | 拒绝 | **不变** | 存储未变 |
| H5（效率声明） | 不允许 | **不变** | 结论方向不变 |

**结论修订**：在预注册的 GT bbox 口径下，**A 的目标区域保真度最高，B 次之，C 最低**。
原报告"H3 成立"以及第一轮修订"H3 撤回、三组持平"**都不成立**；正确结论是
**H3 被拒绝**，C 的 foveation 表示在"真实目标未被 ROI 命中"时会明显丢失细节。

这一结果同时解释了 ROI 命中率（58.3%）为什么是关键指标：它不只是"选得准不准"，
而是直接决定 C 在目标区域上的回溯能力。

## 6. 未受影响的结果

单图时间、显存、CPU/RAM、特征字节、Recall@1/5、mAP@10、相似度 AUC、ROI 命中率
均未使用该坐标路径，数值不变。

## 7. 局限

- 仍然只在合成数据（24 张基准图、72 条查询）上评估。
- 该指标衡量"可见像素保真度"，对色域/显示链路不敏感（管线本身不做 ICC 变换）。
- 覆盖率 < 1 的样本按可见部分比较，可能略高估 A 的边缘区域表现；逐图覆盖率已公开。
- C 的合成规则中，马赛克为 1/2 画布，因此 ROI 未覆盖处的上限受画布尺度限制；
  这是 C 表示的真实上限，不是测量缺陷。
- 逐图 `gt_box`、`attended_box`、覆盖率与三变体 PSNR/SSIM 均在
  `artifacts/experiments/EXP-0001-backtrack-corrected.json` 中公开。
